# DS3D — 黑暗之魂3 二维重制

使用 Rust、WebAssembly 和 WebGL2 制作的黑暗之魂3 2D俯视角重制版。

## 功能特性

- **6个DS3原作区域**，还原正确流程：灰烬墓地 → 传火祭祀场 → 洛斯里克高墙 → 不死聚落 → 幽邃教堂 → 冷冽谷的伊鲁席尔
- **无缝地图过渡**：灰烬墓地与传火祭祀场之间可自由步行穿越
- **5个独特Boss**，各自拥有3种攻击模组、多阶段变化和动作特效
- **动作战斗系统**：轻攻击、重攻击、弹反、翻滚、锁定目标、武器切换
- **RPG系统**：角色属性、灵魂升级、武器强化、背包、原素瓶回复
- **篝火系统**：休息、升级、区域传送
- **地图物品与宝箱**（含宝箱怪）
- **NPC**：铁匠（武器强化）、防火女（升级）、侍女（购买道具）
- **后期处理特效**：动态光照、屏幕震动、慢动作、伤害数字
- **存档系统**：localStorage 本地存储
- **新周目（NG+）** 支持难度递增

## 构建与运行

```bash
# 编译 WASM 包
wasm-pack build --target web --dev

# 部署到静态目录
rm -rf static/pkg && cp -r pkg static/pkg

# 启动本地服务器
python3 -m http.server 8080
```

在浏览器中打开 `http://localhost:8080/static/`。

## 技术栈

- **Rust 2024** 通过 `wasm-pack` 编译为 WASM
- **WebGL 2.0** 渲染（精灵批量绘制、后期处理、光照）
- **HTML/CSS** UI叠加层（血条、Boss名称、菜单）
- 无外部游戏引擎，从零构建

## 项目结构

```
src/
├── ai/          # Boss AI、仇恨表、状态机
├── audio/       # Web Audio 音效
├── bridge/      # WASM入口、游戏主循环
├── combat/      # 武器、伤害计算
├── core/        # 相机、输入、变换、时间
├── entity/      # 玩家、敌人、Boss、实体接口
├── game/        # 游戏状态、菜单
├── render/      # 精灵批量渲染、纹理、后期处理、UI
├── rpg/         # 角色属性、灵魂升级
├── save/        # 存档、篝火状态
└── world/       # 区块、碰撞、导航网格、图块集
```
